A chat is a conversation between you and one or more characters. Every chat lives on the main screen at `/`: the **Chats** rail on the left lists your chats, the open chat fills the middle, and the **Participants** rail on the right lists its characters. Opening `/` takes you back to the chat you opened last.

The pages in this section cover:

- [Messages and swipes](messages.md): reading, editing, regenerating and tidying up messages.
- [The composer](composer.md): writing and sending messages, attachments and guides.
- [Group chats and turn-taking](group-chats.md): who replies, in what order, and auto mode.
- [Chat settings](chat-settings.md): the settings dialog and injections.
- [Sharing and the catalog](sharing.md): inviting people into a chat, sharing your content, and the catalog.

## To create a chat

1. In the **Chats** rail, select **New chat** (the pen icon).
2. Optionally type a **Name**. A chat without a name is listed as "Untitled chat".
3. Pick at least two characters under **Participants (pick at least 2)**.
4. Under **You play as**, pick the character you speak as, or leave it at **Choose later**.
5. Pick a **Greeting** (see the table below).
6. Select **Create**.

The chat opens with its greeting already posted. If you want a character to speak for you as well as the others, see [Group chats and turn-taking](group-chats.md).

### Greeting options

| Option | What it does |
| --- | --- |
| **No greeting** | The chat starts empty. |
| A character's name | That character posts its greeting first. |
| **A random character** | One character that has a greeting is picked at random. |
| **Every character (one message each)** | Each character that has a greeting posts one, in speaking order. |
| **Narrator (write it below)** | You write the opening message yourself, and it is posted by an author named "Narrator". |

A character's opening message carries all of its greetings as swipes, so you can flip to another opening with the swipe arrows. In a one-on-one chat the first greeting shows; in a group a random one shows. The player character never greets.

## To find a chat

- Select **Search chats** (the magnifier) in the **Chats** rail. Type part of a name in **Chat name**, or narrow the list by tags. Select **Close search** to clear the filter. See [Tags](../tools/tags.md) for the tag filter.
- Chats other people invited you into are listed under **Shared with me**, each with its owner's handle.
- Select **Hide chats** to collapse the rail and give the chat more room.

Conversations with the built-in assistant appear in the same list, marked with a sparkle. Start one with **New Mythweaver conversation**; see [Chat with Mythweaver](../tools/assistant.md).

## To rename a chat

1. Open the chat and select **Chat settings** in its header.
2. On the **Basics** tab, change **Name**.
3. Select **Save**.

## To delete a chat

1. Open the chat and select **Chat settings**.
2. Select **Delete**, then confirm.

> [!WARNING]
> Deleting a chat also deletes all of its messages. There is no undo. Only the chat's owner can delete it.

## To work with many chats at once

1. Select **Bulk Select** in the **Chats** rail. A checkbox appears next to each role-play chat (assistant conversations can't be selected).
2. Tick the chats you want. Shift-click to tick a range.
3. Use the selection bar:
   - **Edit…** sets **Reply strategy**, **Group cards**, **Allow self responses**, **Max turns**, **Auto mode delay** or **Model** on every selected chat.
   - **Tags…** adds or removes tags.
   - **Delete** deletes the selected chats and their messages.
4. Select **Done with Bulk Select** when you are finished.

You can also export a chat from its settings dialog, and import chats with the **Import** button at the bottom of the rail. See [Import and export](../tools/import-export.md).

## Unread marks

A chat with activity you have not seen yet, such as a new message or a reply still being written, is highlighted in the **Chats** rail until you open it. Each person in a shared chat has their own read position, so your marks don't change when someone else reads the chat.

While the browser tab with an open chat is in the background, the tab title starts with the number of new messages, such as "(3) ", and the site icon shows a badge. Both clear when you come back to the tab. To be told about replies when you are away, see [Notifications](../account/notifications.md).
